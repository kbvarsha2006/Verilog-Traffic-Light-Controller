# Verilog-Based Traffic Light Controller

## Project Description
This project implements a traffic light controller using Verilog HDL. It controls traffic signals for two roads: North-South and East-West.

## Objectives
- To design a traffic light controller using Verilog.
- To understand Finite State Machines (FSM).
- To simulate traffic signal operations.

## Software Tools Used
- Visual Studio Code
- Icarus Verilog
- GTKWave

## Traffic Light Sequence
1. North-South Green, East-West Red.
2. North-South Yellow, East-West Red.
3. North-South Red, East-West Green.
4. North-South Red, East-West Yellow.

## Simulation
The design was simulated using Icarus Verilog, and the output waveforms were viewed using GTKWave.

## Project Files
- traffic_light.v – Main Verilog design.
- traffic_light_tb.v – Testbench.
- traffic_light.vcd – Simulation waveform.

## Conclusion
The traffic light controller was successfully designed and simulated using Verilog HDL.
